# Sigma Jewellers — Luxury Fine Jewelry

A premium, minimalist frontend landing page for **Sigma Jewellers**, showcasing timeless luxury and handcrafted fine jewelry. This single-page application highlights featured masterpieces, details the brand's heritage story, and provides an elegant user interface for elite clientele.

---

## 💎 Features

*   **Hero Section:** A sophisticated greeting banner featuring the brand's core motto, *"Crafted Perfection"*, and an immediate call to action.
*   **Featured Masterpieces:** A curated, high-end display grid showcasing key products with pricing:
    *   **Solitaire Diamond Ring** — `$4,500`
    *   **Elegance Gold Necklace** — `$6,200`
    *   **Classic Diamond Earrings** — `$2,900`
*   **Consultant Modal Interactivity:** Clicking "View Details" triggers an elegant pop-up modal connecting users directly with luxury consultants.
*   **Heritage Showcase:** A dedicated brand storytelling section detailing the legacy of gold, diamonds, and precious gemstones.
*   **Fully Responsive:** Designed seamlessly for mobile, tablet, and desktop viewports.
